关于 DevKit
面向开发者的一站式效率工具集合。纯前端运行，数据不出浏览器。

设计原则

  • 极简界面，零学习成本
  • 客户端运行，数据不出浏览器
  • 键盘优先，⌘K 快速导航
  • 即用即走，无需注册

技术栈

  • HTML / CSS / Vanilla JS
  • 零依赖，单文件部署
  • OKLch 色彩系统
  • Directory 列表布局

工具列表

  • JSON 格式化 — 格式化 / 压缩 / 验证
  • 正则验证器 — 实时匹配 / 捕获组
  • 日志分析器 — 筛选 / 过滤 / 统计
  • 2FA 验证码 — TOTP 生成 (开发中)
  • 翻译工具 — 多语言互译 (开发中)
  • ADB 自动化 — 设备管理 (开发中)

隐私

所有数据处理在浏览器本地完成，不上传任何输入至服务器。
